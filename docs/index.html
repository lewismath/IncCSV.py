IncCSV.py

A Python implementation of the INC file format — lightweight, self-describing tabular data. Metadata travels with the file. Install with pip install inccsv.

These pages run live Python in the browser via Pyodide. No installation needed.

Edit INC text and watch it parse live. Write back to canonical form.
